# ft_ping
`ft_ping` is a school project in which I have to recreate the `ping` binary from [inetutils-2.0](https://github.com/guillemj/inetutils/tree/427778551b0651d24b0c4d521a0b32be4fef06fd).
## Objectives
I have to manage the options `-v` and `-?`, over `IPv4` with hostname parsing.
I can optionally add more flags to the project.
## Roadmap
- [ ] Option parsing (`ft_getopt`)
- [ ] Verbose option `-v`
- [ ] Help option `-?`
- [ ] Custom TTL option `--ttl`
- [ ] Packet count option `-c`
- [ ] Timing options `-W` and `-i`
- [ ] Testing :D
